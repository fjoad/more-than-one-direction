# There Is More to Refusal in Large Language Models than a Single Direction

Code and data for the EMNLP 2026 paper.

Prior work reports that refusal in instruction-tuned LLMs is mediated by a single activation-space direction. We estimate separate refusal directions for 11 categories of refusal and non-compliance and find that they are geometrically distinct, yet steering along any of them produces nearly the same refusal/over-refusal trade-off. Sparse autoencoders show why: the directions share a reusable core of refusal latents plus category-specific tails.

Models: `gemma-2-9b-it`, `Meta-Llama-3-8B-Instruct`, `Qwen-7B-Chat`.
Data: WildGuardMix, SorryBench, CoCoNot, XSTest.

## Setup

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

Model weights, SAEs and the refusal judge are downloaded from HuggingFace and are not stored here:
`google/gemma-2-9b-it`, `meta-llama/Meta-Llama-3-8B-Instruct`, `Qwen/Qwen-7B-Chat`,
`google/gemma-scope-9b-it-res`, `andyrdt/saes-llama-3.1-8b-instruct`, `allenai/wildguard`.

Generation and steering need one 32 GB GPU, or two 16 GB GPUs with the model sharded
(`HookedTransformer.from_pretrained_no_processing(..., n_devices=2)`). The analysis scripts are CPU-only.

## Data

| Directory | Contents |
|---|---|
| `data/sources/` | the 11 evaluation splits and the shared benign pool |
| `data/training_pools/<model>_per_split/` | the 32 non-compliant + 32 benign prompts behind each direction |
| `data/training_pools/train_subset64_working.json` | the Curated-32 pool |
| `data/controlled_test_set/` | the 200-prompt balanced test set (50 per HR/HC/BR/BC) |
| `data/directions/` | extracted difference-of-means directions (`.pt`) |
| `data/refusal_type/` | steered responses and refusal-type labels for Table 5 |
| `data/judge_validation/` | 450 XSTest responses labelled by three annotators, plus WildGuard and string-match verdicts |
| `data/domain_analysis/` | the 2,054 non-compliant prompts, their domain labels, and the consolidated taxonomy |
| `data/transform_experiment/` | the rewritten prompt pools and the rewriting tables they come from |
| `data/clustering/`, `data/sae_latent_labels/` | clustering outputs and SAE latent annotations |

The benign pool is identical across all non-XSTest splits (SHA `4e09c7ae…`), so a direction is determined
only by its 32 non-compliant prompts.

## Notes

Generated responses are not included. Steering and ablation produce tens of thousands of model outputs;
these are regenerated by the scripts above. Directions are included so the geometric results can be checked
without rerunning generation.

Fourteen scripts under `code/data_prep`, `code/refusal_type` and `code/notebooks` still refer to the
directory layout of the original experiment tree rather than to this repository, and need their paths
adjusted before they will run here. The scripts for Appendices K–N and `code/steering/plot_dose_response.py`
resolve paths relative to the repository root and run as-is.

The SAE latent labels in `data/sae_latent_labels/` were produced with a closed API. The labels are included
so Table 14 can be inspected; the calling code is not.
